## Описание

**Weather Diary** — это графическое приложение (GUI) на Python/Tkinter для ведения личного дневника погоды.  
Приложение позволяет:

- ✅ Добавлять записи о погоде (дата, температура, осадки, описание)
- ✅ Просматривать все записи в удобной таблице
- ✅ Фильтровать записи **по дате** и **по минимальной температуре**
- ✅ Удалять ненужные записи
- ✅ Автоматически сохранять данные в файл `weather_data.json`
- ✅ Загружать данные при каждом запуске приложения

## Установка и запуск

### Требования

- Python **3.10 или новее** (скачать: https://www.python.org/downloads/)
- Библиотека `tkinter` входит в стандартную поставку Python.  
  На Linux (Ubuntu/Debian) при необходимости установите:
  ```bash
  sudo apt install python3-tk
  ```

### Запуск приложения

1. Скачайте или клонируйте репозиторий:
   ```bash
   git clone https://github.com/ВАШ_ЛОГИН/weather_diary.git
   cd weather_diary
   ```

2. Запустите приложение:
   ```bash
   python weather_diary.py
   ```

### Запуск тестов

```bash
python -m pytest tests.py -v
```
или без pytest:
```bash
python tests.py
```

## Примеры использования

### Добавление записи

| Поле | Пример значения |
|------|----------------|
| Дата | `03.05.2025` |
| Температура | `18.5` |
| Осадки | `Нет` |
| Описание | `Ясно, небольшой ветер` |

Нажмите **➕ Добавить запись** — строка появится в таблице и сохранится в `weather_data.json`.

### Фильтрация по дате

Введите в поле «Дата» значение `03.05.2025` и нажмите **🔍 Применить фильтр** —  
в таблице останутся только записи за этот день.

### Фильтрация по температуре

Введите в поле «Температура выше» значение `10` и нажмите **🔍 Применить фильтр** —  
отобразятся только записи, где температура выше 10 °C.

### Сброс фильтра

Нажмите **✖ Сбросить** — таблица снова покажет все записи.

### Удаление записи

Выберите строку в таблице (кликом мыши) и нажмите **🗑 Удалить выбранную запись**.

## Валидация ввода

При добавлении записи приложение проверяет:

| Поле | Правило | Пример ошибки |
|------|---------|---------------|
| Дата | Формат ДД.ММ.ГГГГ | `«abc»` — ошибка |
| Температура | Число (целое или дробное) | `«тепло»` — ошибка |
| Описание | Не может быть пустым | Пустое поле — ошибка |
